# Recover explicit original EPS missed by the legacy context/concept reader

The four-issuer source audit found 23 standard basic-EPS facts: 17 in other
or ambiguous scopes and six in additional-dimensional contexts, including
four share-class facts. Exact basic-EPS labels and extension per-share hints
also exist. These aggregate research hints did not promote any observations.

The new source reader supports only the exact standard ordinary-share total:
`ClassesOfShareCapitalAxis=OrdinarySharesMember` or
`ClassesOfOrdinarySharesAxis=OrdinarySharesMember`, alongside explicit same-
namespace accounting scope and with no third dimension. Preference shares,
entity-defined classes, missing scope and other axes remain excluded. The
existing shared context reader defaults are unchanged; the CFO anchor still
requires its existing scope-only context. This EPS option cannot admit a
dimensional CFO/CAPEX or owner-equity amount.

An extension EPS concept requires a ZIP-local, unambiguous schema element
and label locator/arc binding; literal Korean basic or explicit joint
basic-and-diluted EPS naming from the existing whitelist; a nonabstract
duration numeric-DTR perShare item; and a same-instance annual issuer/scope
context with actual KRW/shares units. External taxonomy URLs are not fetched.
Label similarity, diluted-only accounts, currency-only amounts, conflicting
facts and derived EPS calculations cannot add an observation.

The original 2025 CFO must match the independent annual CF source. All EPS
years still come from that one original filing, with no cross-filing 2023
splice. Existing amounts must agree. New proofs contain the versioned context
contract and a digest of the verified literal concept bindings. New source
IDs identify original-file provenance without calling custom concepts IFRS
standard account IDs. Legacy proofs remain valid without reinterpretation.

Only incomplete, no-additional-EPS legacy negatives with no original positive
proof may be rechecked once. Their exact previous review is preserved in the
new receipt-bound review marker. New negatives are never repeated. Revised
receipts use the existing identity reset. At the current saved-source snapshot
205 issuers are eligible, including six requiring a separately verified
same-scope CFO. This is a source queue, not a recovery/full-observation forecast.

Existing 16-issuer, six-minute source passes, bounded interruption retry,
per-issuer checkpoints, shared EPS writer, verified publication and immediate
finite continuation remain. Scoring formulas, EPS definitions and certified
status do not change. Live gains must be measured after source collection.
