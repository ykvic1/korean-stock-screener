# 손절 위험 보정 검증 (2026-11-03)

현재 화면의 구조 손절거리 보정(-3~+2점)은 가설이며 실제 손절 확률이 아니다. 시총 감점은 별도의 연속형 최대 5점을 유지한다. 이번 구현은 과거 검증 엔진을 보강하며 현재 점수·순위·보유 점수를 변경하지 않는다.

## 사건 순서를 아는 사례와 모르는 사례

일별 OHLC만으로는 같은 날 손절가·목표가를 모두 건드린 경우 어느 쪽을 먼저 건드렸는지 알 수 없다. 기존 수익·MFE/MAE 계산은 손절 선도달을 가정한 보수적 경로를 유지한다. 새 집계는 이 가정을 확정적인 역사적 사건으로 오해하지 않도록 다음 수치를 구분한다.

| 항목 | 계산 |
| --- | --- |
| 순서를 구분할 수 있는 손절 선도달 건수 | 보수적 손절 건수 − 같은 봉 양쪽 도달 건수 |
| 손절 선도달 비율 하한·상한 | 확정적인 손절 사건 / 전체, 보수적 손절 사건 / 전체 |
| 목표 선도달 비율 하한·상한 | 확정적인 목표 사건 / 전체, (확정 목표 + 양쪽 도달) / 전체 |
| 손절선 아래 시가 갭 건수 | 진입 이후 시가가 동결 손절선보다 낮아, 손절선보다 불리한 시가로 모형 청산한 건수 |

이 상하한은 **장중 순서 불명확성에 따른 범위**다. 통계적 신뢰구간·미래 손절 확률이 아니며, 호가 깊이·거래정지·가격제한·미체결·추가 슬리피지를 검증한 실제 체결률도 아니다. 기존 비용 가정과 체결 모형을 확인해야 한다.

## 손절거리별 비교

모형의 실제 다음 거래일 진입 시가와 사전에 동결한 손절선의 거리를 사용한다. 구간은 기존 화면 보정 범위를 따라 사전에 고정하고 성과를 보고 재조정하지 않는다.

| 손절거리 | 구간 |
| --- | --- |
| 3% 미만 | `under_3` |
| 3% 이상~6% 미만 | `3_to_under_6` |
| 6% 이상~9% 이하 | `6_through_9` |
| 9% 초과~12% 미만 | `over_9_to_under_12` |
| 12% 이상~15% 미만 | `12_to_under_15` |
| 15% 이상~25% 미만 | `15_to_under_25` |
| 25% 이상 | `25_or_more` |

기간은 기존 21·42·63·126·252거래일 대용 구간이다. 학습·검증 집단을 분리하고 기업행위·시점 정보 검증, 학습/검증 경계 제거, 관측기간 부족 제외, 동일 발행인 중복 신호 억제 **후에** 거리 구간으로 나눈다. 다른 손절거리 구간으로 이동했다고 중복 사례를 다시 허용하지 않는다.

각 구간도 독립적으로 40사례·10발행인·12개 분기라는 기존 탐색 최소 조건을 충족해야 한다. 전체 표본이 크더라도 개별 구간 표본이 부족하면 수익·비율·상하한·손실폭 통계는 `null`이고 건수만 표시한다. 제외 사례 수는 부모 집단에 한 번만 기록한다.

손절선을 넓혀 빈도만 낮추는 선택을 피하기 위해, 기존 손절·목표 도달 비율·MAE·MFE와 함께 다음을 제공한다.

- 순손익을 최초 손절거리로 나눈 평균 위험단위(R) 손익. 비용을 포함한다.
- 최초 손절거리로 나눈 최대 역행폭의 75백분위수. 시가 갭에서는 1R보다 큰 손실이 가능하다.

표시된 자료의 진입 시가로 구간을 정하므로, 신호일 종가 기준 화면 보정값의 사전 예측력으로 곧바로 해석하지 않는다. 손절·목표선 동결, 과거 상장구성·정규장·기업행위 및 실제 자료 검증이 필요하다. 연구 결과의 `usable_for_live_risk_points=false`, 최종 점수 승인 차단은 유지한다.

## 확인 범위

합성 사례로 양쪽 도달·시가 갭·거리 경계·개별 구간 표본 부족·학습/검증 분리·동일 발행인 중복·품질 검증 및 동결 점수 엔진 연결을 검증했다. 실제 종목의 손절 확률이나 현재 보정의 성과가 검증됐다는 뜻은 아니다.
