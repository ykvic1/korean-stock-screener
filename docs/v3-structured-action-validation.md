# 기업행위 공시 접수번호 대조의 연속 처리

2026-11-05 기준으로 과거 공시 후보 정리는 119개 인접 월 구간까지 준비돼 있다.
기존 공식 JSON 대조기는 1회에 후보 2건·실제 조회 시도 6회로 제한되어 있어,
이 단위는 유지하면서 검증된 체크포인트를 따라 여러 묶음을 연속 처리한다.

- 1회 최대 64묶음·공식 조회 시도 384회·55분이다. 실패한 조회 시도도 포함한다.
- 기존 예약 실행은 유지하며, 그 뒤 UTC 02:55·14:55에 연속 처리를 실행한다.
  추가 예약분의 일 상한은 768회다. 제공자의 실제 인증·쿼터 오류에서는 중단한다.
- 수동 실행은 기본 시험 모드다. `feat(v3.0b): structured action continuation`으로
  시작하는 main 병합 커밋은 승인된 이번 개발의 최초 연속 실행을 시작한다.
- 기존 공식 대조기와 같은 쓰기 대기열을 사용한다. 보고서·큐·체크포인트의
  바이트와 해시를 확인하고, 다른 실행이 바꾼 커서는 덮어쓰지 않는다.
- 중단 전 저장된 보고서는 재사용한다. 체크포인트가 진행되지 않은 보고서도
  내용이 일치하면 원본 재조회 없이 이어서 처리한다.
- 원본 공시 ZIP, 종목·기업·접수번호, 원문 응답과 날짜 목록은 공개하지 않는다.
  실행 요약에는 처리 후보 수·공식 조회 시도 수·완료 월 구간 수만 남긴다.

이 단계는 해당 접수번호가 공식 합병·분할·무상증자 JSON 항목과 일치하는지
확인한다. 신고서에 적힌 예정일과 실제 기업행위 완료일은 구분하며,
수정주가·과거 종목 구성·실제 효력일의 독립 검증과 투자성과 검증은 별도다.
대조 결과의 수집만으로 종목 점수나 투자 인증을 변경하지 않는다.
