# V3.0b 후속 안정형 점수 개편안 — 검토용, 운영 미적용

작성 기준: 2026-11-05. 작업 단위: `score-revision-r1`.
기존 수집·공시·기업행위 검증을 우선한다. 이 문서는 새 운영 모델이나 성과 인증이 아니다.
기존 점수/이력/화면/CSV를 덮어쓰지 않는다. 원천자료 재수집은 요청하지 않는다.

기계 확인용 제안은 `config/v3-score-revision-r1.json`, 재무 분포/합계 검증 결과는
`docs/v3-score-revision-inventory.json`에 보존한다. 재현 명령:
`python v3_score_revision_inventory.py --output /tmp/v3-score-revision-inventory.json`.
출력은 종목별 점수가 아닌 집계이며, 입력 SHA-256과 모형 제안 SHA-256을 포함한다.

## 3. 거래·패턴·추세전환 규칙

- 일봉 20/60/120/240거래일, 주봉 5/10/20/60/120주를 모두 산출한다.
  절대 거래대금/당일 거래대금에는 점수를 주지 않는다. KRX 실제 거래대금과 거래량을
  종목 자신의 과거와 비교하며, 가격 상승에 따른 거래대금 증가만으로 고득점을 주지 않는다.
- 장기 증가·지속성·집중도는 하나의 참여 구조를 분해한 제한된 배점이다. 일봉·주봉에서
  같은 증가 사실을 재합산하지 않도록 주봉 2점은 일봉 대비 추가 장기 확인에 한정한다.
- OBV 직접 배점은 4점. 단순 상승은 0점이며, 거래 증가의 지속성이 확인되지 않으면
  OBV 가점만으로 높은 거래점수를 받지 못한다. 미관측은 0점과 구분한다.
- 하락쐐기, 역헤드앤숄더, 이중바닥, 상승깃발, 상승 후 수렴의 종류별 고정 차등을 없앤다.
  삼각형은 선행 상승추세 확인 시 동일 평가, 하락추세에서는 선호패턴 후보에서 제외한다.
  선행추세 미관측은 상승으로 가정하지 않는다.
- 패턴 품질은 형성/돌파 단계, 객관적 형상 완성도, 돌파 확인, 가격 유지, 장기 추세 정합성으로
  비교한다. 동일 시간대 중첩 패턴은 최고 품질 하나만 반영한다. 일·주봉에서 동일 사건이면
  독립 시간범위가 입증되지 않는 한 중복 기여를 차감한다.
- 거래량 영역의 매물 소화는 거래·가격 경로, 기술영역의 확인은 패턴 돌파 사건의 신뢰도다.
  같은 거래량 폭증을 두 번 보상하지 않는다. 확인 품질을 패턴 점수 안에서 반영할 경우
  별도 1.2점으로 다시 더하지 않으며, 사전에 배점 귀속을 고정한다.
- MA 전환 5점: 일봉 20/60/120에 0.5/0.6/0.9, 주봉에 0.6/0.9/1.5를 제안한다.
  가격 로그로 스케일을 맞춘 과거/최근 MA 회귀기울기, 과거 하락 지속기간, 둔화/평탄화/
  양전환/지속/중장기 확산을 구분한다. 단순 현재 양의 기울기만으로 최고점을 주지 않는다.
- 초기 연구창: 일봉 과거 60거래일·최근 20거래일, 주봉 과거 26주·최근 8주.
  일봉 5/10거래일, 주봉 3/6개 완성봉으로 유지 여부를 비교하고 구간 경계는 연속 보간한다.
  이는 검증할 후보이며 확정 임계치가 아니다. 120기간 MA와 회귀창 확보 전에는 미관측이다.
- 주봉은 거래소 주간 마지막 예정 세션이 마감된 봉만 사용한다. 달력 금요일 이전이라도
  휴장 등으로 주간 거래가 끝났는지 거래일 달력으로 확인한다.
- 교차 발생의 위치와 MA 기울기 변화는 별도 사실이지만, 교차 이전 하락 이력 없이
  동일 교차만으로 전환점수를 복제하지 않는다. 거래량은 전환점수의 추가 가점 대신 확인/상한 조건이다.

## 4. 실제 재무 분포와 위험감점 제안

입력: 기존 `docs/v3-dart-bulk-history.json`, 기준일 2026-11-04, 2,501종목,
2022~2025년. 네 연도에 같은 회계범위가 존재할 때 CFS 우선, 없으면 OFS를 선택했다.
지표별 분모·필수 필드가 없는 관측은 제외했다. 공시 효력일의 과거 시점 인증 자료가 아니다.
표본분포는 현재 상장 구성 기준으로 생존편향이 있을 수 있다.

| 지표 | 유효 표본 | 5백분위 | 중앙값 | 95백분위 |
|---|---:|---:|---:|---:|
| 최신 자기자본/자산 % | 1,631 | 22.1672 | 59.3393 | 91.4421 |
| 최신 부채/자산 % | 1,632 | 8.5579 | 40.6922 | 77.8328 |
| 최신 영업이익률 % | 2,046 | -69.4548 | 2.8369 | 19.6533 |
| 4년 중 영업적자 비율 | 2,065 | 0 | 0.25 | 1 |

자기자본이 0 이하인 관측은 8건. 위 범위는 업종 중립 임계치가 아니며,
특히 금융/지주/일반 제조업에 동일 부채 기준을 적용해서는 안 된다.

연속 함수 `H(x)=3u²-2u³`, `u=clamp(x,0,1)`를 사용한 **연구 후보**:

| 위험군 | 입력/계산 후보 | 미확인 조건 |
|---|---|---|
| 자본 훼손 | `r_equity=H((0.22-equity/assets)/0.22)` | 자산·자본·자본금 또는 회계범위 불명 |
| 부채/상환 | 비금융 업종의 `H((부채/자산-업종Q75)/(업종Q95-업종Q75))`; 상환·이자보상 위험과는 최대값으로 묶음 | 업종표본 30 미만, 정상 부채구조/이자·만기정보 부족 |
| 구조 적자/현금 | 같은 범위 3~5년 적자 비율 × `H(연속적자연수/3)` × `H(평균 영업손실률/0.20)`; 반복 CFO 악화·상환능력은 같은 위험군의 최대값 | 일회성/구조성 구분, 기간·CFO·CAPEX·범위 검증 부족 |

22%와 20%는 분포를 참고한 후보값이다. 22%는 자기자본/자산 하위 5% 부근이고,
영업손실률 20%는 극단 이상치의 지배를 줄이는 후보 상한이다. 성과로 보정된 숫자가 아니다.
장부 자기자본이 양수여도 자본잠식일 수 있으므로 자본금 대비 잠식률을 확보하면
`max(r_equity, H(잠식률))`로 결합한다. 자기자본<=0만으로 부분잠식을 판별하지 않는다.

**감점 크기(양수)**: `risk_deduction = 5 * max(r_equity, r_solvency, r_structural)`.
합산 대신 최대 심각도를 적용해 자본훼손·부채·적자의 연쇄 중복감점을 방지한다.
각 위험군도 관련 지표의 최대값으로 묶는다. 기본 재무점수는 경쟁력, 이 보정은 중대한
생존위험만 담당한다. 기본 재무 배점과의 한계효과/상관분석에서 과도한 이중 불이익도 점검한다.
실제 자본잠식·상환위험 경고는 점수와 별도로 유지한다.

필수자료가 부족하면 `risk_status=unknown`이다. 이미 확인된 위험의 감점은 하한으로
표시할 수 있지만, 미관측 위험을 0이라고 인증하거나 안전으로 표시하지 않는다.
현재 공개 연간 자료만으로 이자보상·만기·반복 CFO/FCF를 모두 검증할 수 없어
**본 감점식의 운영 적용은 보류**한다.

## 5. 최종 점수·결측·이력

`final = clamp(observed_base - capital_deduction + stop_adjustment - risk_deduction, 0, 100)`.
시총/재무 감점 크기는 양수다. 범위는 각각 0~5, 손절 보정 -3~+2.
당일 거래대금 보정과 산업점수는 0. 섹터와 시장 대비 20/60/120일 상대강도는 참고정보다.

결측을 실제 0으로 저장하지 않는다. 관측 합계, 확보배점, 개별 기준일을 각각 보존한다.
확보배점으로 점수를 100점까지 부풀리지 않는다. 새 모델 입력이 없으면 기존 모델 값을
새 버전으로 이름만 바꾸지 않는다. 종목별 마지막 유효 점수와 버전은 그대로 남긴다.
이력 키는 `(issuer_identity, model_version, score_asof, source_digest)`로 분리하고
상장폐지/코드변경 식별자를 유지한다. 모델별 비교는 같은 동결 입력과 같은 관측항목에서 한다.

## 6. 구현·비교·운영 반영 게이트

1. 진행 중인 수집/공시대조/기업행위 검증을 안정화하고 실제 완료 기준을 기록한다.
2. 본 세부 배점·위험 후보를 확인한 후 별도 `v3-stable-r1-research` 엔진을 구현한다.
3. 현재 모델과 동일 스냅샷으로 병렬 산출한다. 기존 운영 모델 기본값은 유지한다.
4. 상위 50/100/200 구성, 시총 구간, 코스피/코스닥, OBV/거래/전환 기여도,
   재무 고위험 순위 이동, 지표 상관 및 교차 제거 비교를 만든다.
5. 확보배점 우선 정렬을 후보 모델에서는 제거하고 원시 관측 기반 안정형 점수 순으로 비교한다.
   결측 편향을 숨기지 않도록 확보배점 구간별 비교와 동일 관측집합 비교를 함께 제시한다.
6. 상승초기 정의를 사전 고정하고 1/2/3/6/12개월 수익·MAE·구조손절 선도달률을 비교한다.
   비용·상폐·정지·같은 봉 목표/손절 순서 불확실성·관측기간 미충족을 반영한다.
7. 수정주가/공시효력/과거 구성 검증 전 성과는 잠정 연구결과로만 표시한다.
8. 모바일·상세·CSV·서버는 동일 계산 결과/버전을 읽고 각각의 보정값을 노출한다.
