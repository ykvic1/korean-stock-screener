# 실제 거래대금 중장기 지속성 연구 (2026-11-03)

기존 수집량 집계에 종목별 실제 분석 가능 범위를 추가한다. KRX 직접 보고 `ACC_TRDVAL`에서 만든 비공개 5거래일 파생자료만 읽으며 원본 가격·거래대금·종목별 금액은 공개하지 않는다. 새 KRX API 호출은 없다.

## 비교 방법

- 최근 20·60·120·240거래일과 각각 **겹치지 않는 직전 동일 기간**의 거래대금을 비교한다. 240일 비교에는 총 480거래일, 96개 5거래일 묶음이 필요하다.
- 종목마다 두 구간이 모두 완전해야 증가율을 계산한다. 결측을 0으로 대체하지 않으며, 직전 기간 집계값이 0인 경우도 배율은 미산출이다. 이 0에는 10만원 단위 반올림의 영향이 포함되므로 원래 거래대금이 정확히 0이었다고 단정하지 않는다.
- 최근 구간에서 직전 평균을 초과한 5거래일 묶음의 비중과 가장 큰 묶음의 금액 비중을 구분한다. 같은 평균 증가율이라도 한 묶음의 폭증과 여러 묶음의 지속 증가를 구분한다.
- 5거래일 묶음 안의 하루 집중도는 복원할 수 없다. 이를 일별 급증·정확한 주봉·정확한 금액형 OBV로 표현하지 않는다. 금액은 기존 10만원 단위 집계의 정밀도다.

## 실제 이력 재계산

`v3_krx_money_horizon_coverage.py`는 체크포인트·꼬리 SHA 검증 후 고정된 달력 후보의 **정확한 파일 경로와 시작·종료일**을 확인하면서 최신 최대 96개 과거 묶음을 읽는다. 중간 파일 누락을 재색인하여 연속 이력으로 처리하지 않는다. 읽기 전후 체크포인트가 바뀌면 게시를 중단한다.

집계 모집단은 **최신 완성 묶음에서 5일 완전 관측된 종목-시장쌍**이다. 현재 상장 전종목 모집단 또는 상폐·코드변경이 검증된 과거 종목구성을 뜻하지 않는다. 고정 과거 원장을 보존하며 최근 증분 자료와의 연결 여부·종료일은 별도로 표시한다.

### 최근 증분 연결 (2026-11-03)

집계기는 고정 과거 원장을 변경하지 않고 `money-forward-checkpoint`의 완성 5일 묶음을 최신순으로 앞에 연결한다. 과거 5일 그룹에 포함되지 않은 마지막 2일이 증분 달력의 첫 2일과 일치해야 하며, 증분 체크포인트의 달력 접두 해시·마지막 파일 SHA·시작/종료일을 검증한다. 연결 부분의 파일이 없거나 해시·날짜가 다르면 게시를 중단한다.

모집단은 이제 **연결된 최신 완성 묶음의 종목-시장쌍**이고, 종료일은 `analysis_complete_cohort_endpoint`다. 기존 `historical_archive_endpoint`는 고정 과거 원장의 종료일로 남긴다. 최근 달력 후보 중 미완성 1~4일과 아직 수집하지 않은 완성 묶음을 구분하여 제외한다. 예를 들어 종료일이 10월 28일이고 그 뒤 4일 후보가 있으면 이를 11월 3일 자료로 재표기하지 않는다.

과거·증분 합계 최대 96묶음만 읽고, 양쪽 체크포인트 모두 읽기 전후 같아야 한다. 최근 증분 수집이 완료될 때도 다시 집계한다. 이전에 게시한 분석 종료일보다 후퇴하는 결과는 저장하지 않는다. 이는 현재 정규장·기업행위·정확한 주봉이나 최종점수 인증을 뜻하지 않는다.

공개 `v3-krx-money-horizon-coverage.json`에는 기간별 완전 관측·직전 동일기간 비교 가능·0원 기준값·평균 증가·모든 최근 묶음의 평균 초과 **건수**만 담는다. 이는 산술적인 관측 수이고 검증된 매수 신호나 수익 확률이 아니다. 수집 성공 후와 정기 점검 때 다시 계산한다.

## 남은 완료 조건

현재 거래일과의 연결, 정확한 주봉·일별 금액형 OBV, KRX 정규장 단독 출처, 기업행위·상폐 종목의 과거 구성, 손절 선도달·MFE/MAE·기간별 수익 검증은 별도로 남아 있다. 이번 집계는 `scoring_allowed=false`, 기존 종목점수·순위 유지 원칙을 따른다. 시총 감점은 사용자 지정 연속형 최대 5점을 유지한다.
