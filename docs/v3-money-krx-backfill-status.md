# V3.0b 실제 거래대금 10년 수집 경로 (2026-11-03)

## 확정된 사실과 제한

- 기존 KRX 490/490 **파생 코호트**에는 거래 주식수 기반 팩터만 존재한다. 이를 실제 거래대금으로 소급 변환하지 않는다.
- KRX 주식 일별매매정보의 `ACC_TRDVAL`을 출처로 사용한다. `TDD_CLSPRC × ACC_TRDVOL`은 거래대금으로 인정하지 않는다.
- 새 경로는 동일한 2016-10-17~2026-10-16 날짜 후보 490개 5거래일 코호트를 **별도 체크포인트**에서 다시 읽는다. 이전 가격/실적 이력 및 기존 490/490 완료 기록을 덮어쓰지 않는다.
- 최근 거래일에 가까운 5일 코호트부터 과거로 역순 수집하여 20/60/120/240일용 최근 연구 데이터 확보를 앞당긴다.
- 각 5일 코호트마다 KOSPI/KOSDAQ 합계 10회 API를 읽되 응답 원본·일별 가격·일별 거래대금은 영구 저장하지 않는다.
- 암호화폐·NXT·시간외 자료 혼합을 허용하지 않으나, 이 KRX 일별 API가 **09:00~15:30 정규장 전용**인지 독립 검증 전에는 `regular_session_only_verified=false`를 유지한다.
- 이전에 승인된 개인용 비공개 파생지표 연구 저장소 `ykvic1/korean-stock-private-data`에만 수집한다. 원천 소스 공개 저장소/로그/아티팩트 업로드 금지. 추가 데이터 라이선스 적용 여부는 계속 확인한다.

## 기간 축을 충족하기 위한 순서

| 단계 | 자료·검증 | 현재 상태 |
| --- | --- | --- |
| A | `ACC_TRDVAL` 기반 5거래일 합계·후반/전반 비교·서명 금액 흐름 | 코드 추가, 검증 후 수집 착수 |
| B | 실거래일 20/60/120/240일 연속 코호트 집계와 결측 격리 | 아직 실전 연결 전 |
| C | 정확한 달력 5/10/20/60/120주 및 금액형 OBV | 5일 코호트 ≠ 달력 주봉, 별도 주간 정합성 필요 |
| D | 장기 유입 지속성과 조정 중 거래대금 수축, 가격 괴리 | 통계적 검증 후 배점 결정 |
| E | 시총·유동성 구간별 손절 선도달/MAE/MFE 성과 검증 | 적정 가점·감점 사후 교정 필요 |
| F | 기존 거래량·OBV 20점 교체와 PER/EPS 성장·내재가치 통합 검증 | 현재 **미완료** |

5일 집계 기록에는 직접 보고된 거래대금 총합의 10만원 단위 집계, 5일 중 4개 가격변화 구간의 매수/매도 방향에 따른 거래대금 압력, 초반 2일 대비 후반 2일의 증가 강도 및 결측 표지만 저장한다. 5일 코호트 간 첫날의 주가 방향, 정확한 주봉 종가, 상장폐지·합병/분할 정합성은 아직 증명되지 않았다.

따라서 `investment_scoring_allowed=false`를 유지하고 **실전 최종점수·기존 종목순위에 아직 섞지 않는다.** 새 자료가 중단되거나 검증 실패하면 해당 구간만 보류하고 이전의 원점수·순위·기준일을 보존한다.

## 운영

- 새 전용 체크포인트 `derived/money-historical-checkpoint.json`을 **비공개 저장소**에서 독립적으로 관리한다.
- 작업 한 번 최대 16코호트 / 160 KRX 시장별 조회, 각 파일 저장과 검증 직후 체크포인트를 진행한다.
- 주어진 경로의 기존 파일이 존재하면 검증·채택만 하여 API를 재호출하지 않는다.
- 회귀 테스트가 새 코드에 대한 위양성 또는 장기간 이력 누락을 보이면 수집을 중단하고 기존 점수는 그대로 둔다.
- 퍼블릭 화면에는 합산 실제 거래대금의 추정치 또는 `확정 OBV`로 표시하지 않는다. 원자료·거래일·정규장 검증 후 공개할 수 있는 비재구성형 지표만 따로 승인한다.
