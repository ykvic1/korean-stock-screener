# R1a 잠정 운영점수 조기 전환

## R1b 후속: 일·주봉 MA 기울기 전환 5점 연결 (2026-11-05)

R1a의 별도 저장 이력과 기존 모델은 유지한다. `v3-stable-r1b-operational-research`는
완전한 과거 하락기울기와 최근 상승기울기·최소 유지 구간을 모두 가진 경우에만
일봉 20/60/120(0.5/0.6/0.9점), 완성 주봉 20/60/120(0.6/0.9/1.5점)을
종목별 관측한다. 한 번의 골든크로스와 중복되는 점수를 주지 않는다.

새 원천은 다음 전 종목 가격 이력 스캔부터 제공된다. 아직 해당 관측이 없는 종목의
5점은 미확보로 남고, 기존 R1a의 동일 지표 관측은 이름·시장·기준일을 확인한 뒤
R1b로 이관한다. 브라우저는 갱신 전 R1a 출력도 읽을 수 있어 게시 순서로 인한
운영 화면 중단을 방지한다.

모든 자료가 있을 때 R1b의 최대 관측 배점은 **86.8/100**이다. 거래 세부구조 12점과
독립 돌파확인 1.2점은 여전히 별도 구현·검증이 필요하다. 이 수치는 관측 가능 배점일
뿐 실제 취득 점수나 공식 시장데이터 인증이 아니다. 미확보 점수의 보정·환산은 하지 않는다.

---

사용자 요청에 따라 공시 효력일·기업행위·성과 검증이 끝나기 전에 기본 화면을 신규 점수로 전환한다.
모델 버전: `v3-stable-r1a-operational-research`. 정식 검증 완료 모델이 아닌 단계적 운영 모델이다.
기존 20/25/20/20/15점 모델과 그 점수 파일·기업별 이력은 그대로 유지한다.

## 적용한 부분

- 전체 배점 25/30/12.5/12.5/20, 산업 배점 0.
- 저장된 장기 거래참여 6점, OBV/가격 괴리 4점, 매물 소화 3점만 관측 점수로 사용한다.
  기존 6점은 여러 기간의 거래참여 종합 관측이다. 이를 새 지속성·집중도 등으로 복제하지 않는다.
- 골든크로스 6점을 기술영역으로 옮긴다. 교차점과 240MA 조건은 기존 원본 검사를 유지한다.
- 패턴은 일봉 8.4/주봉 9.6으로 배정하고 종류별 차등을 없앤다. 형성 후보 70%,
  실제 돌파 관측 100%는 단계 구분을 위한 잠정 계수이며 성공확률이 아니다.
  동일 시간대 패턴은 최고 하나만 사용한다. 삼각형은 60/120일 가격 변화가 모두 양수인
  추세 대용 조건을 충족할 때만 선호 후보로 평가한다. 장기 파동/선행 추세 인증은 아니다.
- 기존 RSI·장기 MA 위치 관측은 새 배점에 맞게 축소한다. 당일 거래 폭증 가점은 이전하지 않는다.
- 재무·가치의 관측 세부항목을 새 배점에 맞춰 계산한다. R1a의 영업항목은 기존 마진 관측이며
  별도 영업이익 성장 지표는 아직 추가하지 않았다. EPS가 없으면 PER 관측분만 가용 배점에 포함한다.
- 기존 모멘텀 15점은 보존한다.
- 확인된 자본 훼손/지속 적자 위험은 제안한 연속 함수로 최대 5점 감점하되,
  금융 업종과 업종 미확인 기업에는 일반 기업의 자기자본/자산 22% 기준을 적용하지 않는다.
  부채 만기·상환능력·반복 CFO·자본금 대비 잠식 검증은 미완료로 표시한다. 안전으로 표시하지 않는다.
- 시총 감점 0~5, 손절 보정 -3~+2, 재무위험 감점 0~5를 각각 노출한다.
- 확보배점 우선 정렬을 없애고 신규 안정형 점수를 먼저 정렬한다. 확보배점은 동점일 때만 사용한다.

## 아직 미관측인 부분

거래 추가 세부구조 12점, 독립 돌파 확인 1.2점, MA 기울기 전환 5점은 R1a에서 계산하지 않는다.
따라서 현재 최대 관측 배점은 **81.8/100**이다. 종목별 결측은 추가로 존재할 수 있다.
미구현 점수를 0점으로 확정하거나, 확보 배점을 분모로 100점까지 부풀리지 않는다.
점수·확보배점·각 자료 기준일을 별도로 표시한다. 추후 이 항목들을 추가하면 R1b 등 별도 버전을 사용한다.

## 이력·비교·운영

새 JSON/CSV는 기존 파일과 독립적으로 생성한다. 종목별 마지막 유효 신규 항목은 이후 자료가
누락돼도 같은 모델 안에서 유지하며, 기존 모델 값을 새 모델의 미관측 항목으로 복제하지 않는다.
`docs/score-history/<model>/<date>-<digest>.json`에 코드·입력 해시별 별도 관측을 보존한다.
상장폐지/코드변경에 대한 기존 이력 관리 기능을 바꾸지 않는다.

기본 목록은 R1a, 정렬 메뉴에서 기존 안정형/원점수와 비교 가능하다. 상세 화면에 두 모델의
점수/순위·보정값·미관측 항목이 함께 표시되며 CSV도 서버에서 같은 결과로 생성한다.
새 파일 검증이 실패하면 기존 모델로 표시를 전환하고, 이를 신규 점수인 것처럼 표시하지 않는다.

별도 워크플로는 저장자료만 재계산하며 제공자 호출·개인 원본 저장소·수집 잠금을 사용하지 않는다.
기존 점수 갱신 성공 후 및 시간별 보완 실행으로 자동 반영한다. 계산 실패 시 공개된 마지막 파일은
그대로 유지한다. 공시 대조·기업행위 검증 일정과 실행 예산은 변경하지 않는다.

성과·손절확률·MAE는 미검증이며 신규 모델의 우월성을 주장하지 않는다. 현재 순위 비교는 관측용이다.
