# 종목별 손절 위험 근거 점검 (2026-11-03)

종목 상세의 점수 분포 아래에 기본 접힘 상태의 **손절 위험 근거 · 자료 점검**을 추가했다. 현재 화면에 이미 있는 가격·손절선·과거 관측 고점 자료를 읽으며 추가 API 호출이나 원천자료 저장은 없다.

## 표시 항목

- 원래 가격자료 기준일과 시장자료 기준일의 일치 여부. 이전 관측도 지우지 않고 원래 날짜를 표시한다.
- 관측 가격 아래 구조 무효화 참고선의 존재 여부와 참고 손절거리.
- `stop_pct`와 표시 손절선 거리의 약식 대조. 기존 안정형 보정과 동일한 ±2%p 허용 범위를 사용한다. 이는 정규장·기업행위 또는 손절선의 투자 타당성 인증이 아니다.
- 과거 관측 고점까지의 참고거리와 해당 거리/손절거리 비율. 과거 고점이 현재 가격 아래에 있거나 손절거리 근거가 없으면 손익비를 만들지 않는다. 미래 목표가나 수익 예측으로 취급하지 않는다.
- 검증된 과거 손절률 표본이 연결되지 않은 상태와 시가 갭·체결 위험 미검증 상태.

자료의 숫자형·유한값·날짜를 확인하고, 표시 거리 불일치·현재 가격 이상 손절선·미래 날짜·결측을 구분한다. 종목 데이터에 임의의 확률·표본수·인증 플래그가 있어도 이 패널에서 인증하거나 확률을 표시하지 않는다. 입력 값과 기존 점수·순위를 변경하지 않는다.

새 JS 파일은 두 진입 경로에서 본체보다 먼저 로드한다. 기능이 로드되지 않은 경우 기존 화면은 계속 동작한다. 현행 손절 보정 -3~+2점과 시총 연속형 최대 5점은 유지한다.

Node 검사에서는 현재/이전 날짜, 보호 역할을 하지 못하는 손절선, 숫자·날짜 결측, 표시 거리 불일치, 임의 확률 주입, XSS와 원본 불변성을 확인한다. 실제 모바일 Chromium 검사에서는 패널의 접기/펼치기와 320·390·430px에서의 가로 넘침을 확인한다.
