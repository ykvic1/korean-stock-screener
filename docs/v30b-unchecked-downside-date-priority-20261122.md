## 검증 경계
1. 실제 후속 실행 전 공식 대조 완료 목록과 현재 진행 중인 실행을 다시 확인해 중복 날짜를 제외한다.
2. 각 신규 날짜의 종목·시장·명칭·상장주식수·OHLC·거래량·거래대금을 같은 공식 응답으로 대조한다. 정규장 세션 범위의 독립 증명이 없는 수치는 세션 인증으로 승격하지 않는다.
3. 주식 교부·상장폐지·코드 변경·수정주가 경로 및 참고선 접촉은 별도 독립 증거가 필요하다. 결측은 결측으로 남긴다.
4. 기존 14개 날짜 재수집, KRX 401 신주인수권증서 9건 재조회, 운영 배점 변경, 소급 실측 성과 생성은 하지 않는다.
