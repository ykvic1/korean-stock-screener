## 이미 구현된 후속 검증 실행 범위
- `v3_historical_pilot_official_prices.py`에는 `downside_followup`(5일), `downside_tail_1`~`downside_tail_5`(22일), `reference_touches`(3일)가 이미 정의되어 있다. 위 27개 미검증 극값 날짜는 **기존 5+22개 배치로 모두 커버하도록 계획**되어 있으며, 이번 문서가 신규 수집 코드나 재실행을 요구하는 것은 아니다.
- `tests/test_v3_historical_pilot_official_prices.py`에는 해당 배치의 날짜·원장 대조 및 중복 방지 테스트가 이미 있다. 배치 정의·테스트 통과는 공식 KRX API 실행 및 대조 성공과 별개다.
- GitHub Actions 수동 실행 범위 `downside_followup`, `downside_tail`, `reference_touches`의 실제 최근 실행·아티팩트 유무를 먼저 확인한다. 기존 성공 배치를 다시 실행하지 않는다.

## 검증 경계
1. 실제 후속 실행 전 공식 대조 완료 목록과 현재 진행 중인 실행을 다시 확인해 중복 날짜를 제외한다.
2. 각 신규 날짜의 종목·시장·명칭·상장주식수·OHLC·거래량·거래대금을 같은 공식 응답으로 대조한다. 정규장 세션 범위의 독립 증명이 없는 수치는 세션 인증으로 승격하지 않는다.
3. 주식 교부·상장폐지·코드 변경·수정주가 경로 및 참고선 접촉은 별도 독립 증거가 필요하다. 결측은 결측으로 남긴다.
4. 기존 14개 날짜 재수집, KRX 401 신주인수권증서 9건 재조회, 운영 배점 변경, 소급 실측 성과 생성은 하지 않는다.
