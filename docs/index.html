KRX 정규장 가격·거래량과 공식 종가 교차검증 전입니다. 기존 환산점수는 보존된 연구값이며 새 종합 100점 확정 점수가 아닙니다. 점수는 상승 확률이 아닙니다. '확보율'은 데이터로 실제 평가한 배점 비중입니다. 수급과 재무가 빠진 종목은 매수 우선으로 분류하지 않습니다.

관심 종목 최대 20개 · 우선 관찰 5개

현재 v2.2 자료에서 상승 전환·수렴 구조, OBV·패턴, 손절 참고선, 데이터 확보율을 확인한 최대 20종목입니다. 우선 살펴볼 5개와 추가 관찰 후보 최대 15개로 구분합니다. 조건을 만족하지 않는 종목을 억지로 채우지 않습니다. 기존 점수순이나 v3 종합 순위가 아니며 매수 추천이 아닙니다. 기관 수급·재무·업황이 확인되지 않으면 반드시 추가 검토하세요.
