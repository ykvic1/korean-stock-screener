## What is actually checked

- Published market, official-listed catalog and existing rolling OpenDART annual book must pass the previous **hard source-day and unique ticker audit** (no future or mixed market census).
- Market close date is compared with actual **Korean calendar date**; it never invents exchange open/close and labels possible multi-day holidays as ambiguous. Older than 4 calendar days is a warning; **14 or more is critical** for prolonged missing publication.
- All-market analyzed/listed coverage reported; below 80% triggers critical. No absent stock silently counted as zero.
- On *new* price publications dated on/after 2026-10-20 (not the historical Oct19 snapshot), no valid **technical25** across 100+ stocks triggers critical; day and completed-weekly pattern observations are audited separately. An absent pattern for an individual stock is not automatically a failed bullish signal.
- The optional 4-year DART evidence file (from PR #133 **only if it was actually generated by an explicitly requested manual pilot**) is revalidated: current-listed membership, distinct issuers, complete 4-year same-scope reports, fiscal years, actual receipt dates and reference math, no forged FCF or full financial15/valuation15/V3 investment rank. Missing file is a warning, not manufactured successful counts.
- Numeric IAS20, Finance15, Valuation15, Sector15 and Momentum10 investment scores remain unverified. A `pass` status means **source-quality tests passed**, not a stock is attractive or the V3 scoring system is ready.

## How it continues to run without manual babysitting

Existing `.github/workflows/v3-six-pillar-source-readiness.yml` now runs:
- When the actual weekday 18:30 full-market **scheduled** workflow succeeds (`workflow_run`), as before.
- **Every Tuesday to Saturday at 07:00 Korea time** by GitHub schedule (`cron: 0 22 * * 1-5` UTC) independently of prior success, to reveal stale data and failed scheduled market collection. This is a conservative daily-check frequency; GitHub scheduled jobs can experience delay.
- Manually (`workflow_dispatch`) and when the checker source code changes on main.

Read-only GitHub Actions permissions `contents:read`, no API keys passed and no KRX/DART/price requests; produces an auditable KST-dated Markdown job summary and time-limited private JSON artifacts **even when a failure is detected**. This is a CI alert signal visible in Actions, **not an automatically sent phone push notification**.

**Do not alter the 18:30 market publisher, rolling OpenDART 8×40 weekdays, staged four-year manual/dry-run-first workflow, live trading decisions or source storage.** Tests include synthetic publisher gap/holidays, dangerous price coverage, forged 4-year receipts/missing scope, no full 100 score or buys, and read-only scheduled workflow safety. Existing full CI and mobile regression must remain green.
