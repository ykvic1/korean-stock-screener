첨부 ZIP은 CHAT에서 기존 GitHub 저장소 ykvic1/korean-stock-screener 의 main 최신 확인 커밋 28273e731279 기준으로 작성한 공식 KRX·OpenDART API 연결 사전 준비 패치야.

이번 작업은 v2.2 운영코드나 스크리너 점수체계를 변경하는 게 아니라, 공식 데이터 연결 검증용 모듈·오프라인 테스트·수동 실행 전용 Actions를 별도로 추가하는 단계야.

1. GitHub main 및 기존 파일의 최신 커밋·변경사항을 확인해.
2. 새로운 작업 브랜치를 만들어 ZIP의 official_api_preparation.patch에 git apply --check 후 적용해. 중복 파일/수정 충돌이 있으면 덮어쓰지 말고 보고해.
3. 새 회귀 테스트 24개와 기존 단위 테스트 전체를 실행해.
4. 인증키 승인이 전부 완료되기 전에는 실 API 호출 금지. python -m official_probe --asof [docs/data.json에 존재하는 완료된 거래일] 로 dry-run만 실행.
5. .github/workflows/official-probe.yml은 workflow_dispatch 전용이므로 기존 자동 daily/quant/reliability 워크플로에 연결하거나 일괄 실행하지 마.
6. 코드와 테스트만 PR로 올리고 CI 확인해. 기존 docs/와 보고서/Excel은 수정·삭제·재계산하지 마. 데이터, API 키, 비공개 결과를 커밋하거나 GitHub Pages에 게시하지 마.
7. KRX와 DART의 개인 계정 승인 및 해당 서비스 이용 승인이 확인된 뒤에만, 사용자가 지시하면 최대 10종목 live probe를 1회 실행해. DART는 최대 2개 회사만 조회.
8. 투자자별 외국인/기관 수급, 정규장 전용 거래량, 기업행위/수정주가 등의 제공 범위와 권한이 확인되기 전에는 IAS 점수나 확정 데이터를 만들지 마.
9. 필요한 GitHub Secrets는 KRX_API_KEY, DART_API_KEY이고 값은 절대 출력·요청하지 마.
10. 실행 보고: PR, 수정파일, 테스트 결과, dry-run 결과, 미검증 항목, API 승인 후 다음 조치를 간단히 정리하고 종료해. v3.0 점수엔진/전 종목 백필/자동 발행은 승인하지 않아.

이번 요청으로 허용하는 외부 작업은 기존 저장소의 별도 브랜치에 첨부 코드 업로드, PR 생성, 오프라인 테스트 및 dry-run뿐이야. KRX/DART 실데이터 호출·main 병합·Pages 배포는 별도 승인받아야 해. 비용/크레딧 낭비를 최소화해줘.
